FOUR WAYS TO READ THE RECORD · YEARLY HOTSPOTS

LIMITS · READ BEFORE USE
  • Hotspots are detections, not burned area. Clouds and thick smoke hide fires, so a quiet month can mean "not seen".
  • Months before Feb 2012 are estimated from MODIS (hatched). Peatland provinces such as Riau carry the largest errors; see "Measured error here".
  • Recent months use near-real-time data with static heat sources removed per cell; FIRMS later replaces them with standard data.
  • For seasonal and historical context, not same-day firefighting. Use NASA FIRMS for tactical alerts.
